# StockScreener

Скринер акций, в котором торговую стратегию можно собрать мышкой, без кода.

Репозиторий для домашних заданий курса СДМ. Каждое ДЗ лежит в своей ветке (hw-1, hw-2, hw-3). Идея взята из нашего командного учебного проекта StockScreener (Django + FastAPI + Celery + Redis).

Моя бизнес-модель по ведомости: Freemium + Subscription.

## Elevator Pitch

Для частных инвесторов, которые хотят торговать по правилам, а не на интуиции, но не умеют программировать, StockScreener это скринер акций с конструктором стратегий. Стратегию (например, RSI < 30 и MACD > 0 и цена выше SMA 200) можно собрать из блоков, без кода, и запустить сразу на весь свой список акций. Расчёт идёт в фоне, результаты потом лежат в истории запусков. В TradingView для такого нужно знать Pine Script и платить от $15 в месяц, а в Finviz и скринерах брокеров условия слишком простые. У нас базовый тариф бесплатный, Pro стоит $9.99 в месяц.
